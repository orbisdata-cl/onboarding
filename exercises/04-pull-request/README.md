# Ejercicio 04 — Pull Request

## Objetivo

Abrir el PR final que certifica que completaste el onboarding.

## Tu tarea

1. Verificar que el CI esté completamente verde en la rama
2. Abrir un PR desde `onboarding/tu-nombre` → `main`
3. Completar el checklist del PR (aparece automáticamente al abrir el PR)

## Criterio de éxito

- CI verde en todos los checks
- PR abierto con el checklist completo
- Un tech lead hace el code review final

## Nota

**Este PR nunca se mergea.** Queda abierto como evidencia de que completaste el onboarding.
